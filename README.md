Respuestas:
-Ejercicio 1:
Que el molde permite agrupar varias propiedades para construir los objetos, sin necesidad de repetirlos una y otra vez de forma separada. Además, con su uso se pueden crear un sinnúmero de objetos.
-Ejercicio 2:
Porque la palabra clave this permite leer y modificar todas las propiedades dentro del molde de manera separada sin afectar a las demás.
-Ejercicio 3:
Que así, si las reglas cambian, no hay necesidad de modificar el resto del código que consume al objeto, sino que solo basta con cambiar el método interno.
-Ejercicio 4: 
Que se rompería la integridad del sistema, lo cual podría ocasionar que se procese como que el libro se volvió a prestar, aun sabiendo que este ya había sido prestado antes, y además la persona no recibiría un mensaje que le advierta que no puede prestarlo.
-Ejercicio 5:
Que así cada usuario que utilice el código puede construir sus propios objetos, eligiendo como quiere que sean definidas todas las propiedades por separado. Además, esto facilita la escalabilidad del código, dejando a un lado el tener que declarar las variables manualmente por cada registro.
